### Featured Product — [PanoRA](https://github.com/uplifAPP/panora-desktop)

**PanoRA** is a local-first desktop productivity workstation built for macOS (Apple Silicon & Intel) and Windows 10/11. It brings clipboard history, zero-duplication file organization, screen capture, 60 FPS video studio, on-device OCR, and encrypted LAN sync into a single lightweight application — with **zero cloud dependency**.

| Capability | Highlights |
| :--- | :--- |
| **Smart Clipboard & Cards** | Zero-duplication file referencing, multi-card sequential Paste Queue, Quick Look overlay, custom workspaces, and 11-language search engine. |
| **Capture & Video Studio** | Region & scrolling screenshot capture, annotation canvas, 60 FPS screen recording with webcam bubble, mosaic censor, DSP audio cleanup, and WebP/AVIF & audio extraction. |
| **On-Device OCR & Tools** | Hardware-accelerated OCR & QR/barcode scanning (Apple Vision on macOS, WinRT on Windows), pixel loupe color picker, and zero-dependency PDF slice & merge. |
| **Encrypted Vault** | Local AES-256-GCM encryption with `scrypt` key derivation, Touch ID unlock (macOS), auto-lock, and 16-character emergency recovery key. |
| **Pano Mesh & AirBridge** | Serverless P2P sync between Mac & Windows over local Wi-Fi, plus an ephemeral QR-paired mobile web portal (AirBridge) for instant phone transfers. |

---

### Engineering Principles

- **Local-First by Default:** Your cards, media, and encrypted vault stay strictly on your own disk — never uploaded to third-party servers.
- **Zero Telemetry:** No behavioral analytics, no background tracking, and no forced cloud accounts.
- **Native OS Parity:** Purpose-built macOS (Swift / Vision / AppKit) and Windows (WinRT / Win32) integrations for fast, native workflows.
