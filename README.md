# Uplif

Independent software studio building local-first desktop applications for macOS and Windows.

## Products

### [PanoRA](https://github.com/uplifAPP/panora-desktop)

Local-first desktop workstation for macOS (Apple Silicon and Intel) and Windows 10/11. Combines clipboard history, zero-duplication file organization, screen capture, 60 FPS video recording, on-device OCR, an AES-256-GCM encrypted vault, PDF tools, and LAN peer-to-peer transfer in one application with no cloud dependency.

- Product page: [uplif.app/panora](https://uplif.app/panora)
- Documentation & repository: [uplifAPP/panora-desktop](https://github.com/uplifAPP/panora-desktop)
- Issue tracker: [uplifAPP/panora-desktop/issues](https://github.com/uplifAPP/panora-desktop/issues)

## Design Standards

- **Local-first storage:** User data stays on disk in standard OS directories rather than remote cloud databases.
- **No telemetry:** No behavioral analytics, ad SDKs, or background tracking.
- **Native OS integration:** Platform-specific system frameworks on macOS (Vision, AppKit, CoreGraphics) and Windows (WinRT, Win32).
